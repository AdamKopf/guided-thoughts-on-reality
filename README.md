## 1. Where it started

The original question was: *what is the most general definition of information, one that covers all possible universes, realities and realms?*

The working definition became: **information is distinction.**

Related ideas, for orientation only:
- Gregory Bateson: information is "a difference which makes a difference".
- George Spencer-Brown, *Laws of Form*: a calculus built on the act of drawing a distinction.
- Claude Shannon: a message is one selection from a set of possible messages.

## 2. Core definitions (current state)

| Concept | Definition |
|---|---|
| **Information** | Distinction: one possibility as against the others. Equivalently, selection from what is possible. |
| **Existence** | Being a distinct possibility. "Possible" and "existing" are the same thing. |
| **The absolute** | Beyond every distinction, including exists/doesn't exist and limited/unlimited. It allows every distinction and every limitation to appear within it or relative to it. |
| **Contradiction** | A label that points to nothing (an "empty pointer"), or something that isn't a real contradiction. |

## 3. My key commitments and the reasoning behind them

### 3.1 Distinction doesn't need to affect anything

An earlier proposal said information needs a second system: a difference in one thing that constrains a difference in another, like tree rings and rainfall. **I rejected this.**

My example: imagine a universe made only of the quality of "yellowness". It affects nothing else. It's still a distinction. The only thing it relates to is the absolute.

Refinement that was accepted: the contrast doesn't disappear. Yellowness is distinct *from the other possibilities* in the absolute. So distinction is relational, but the other side of the relation is possibility space, not a second physical system. No observer is needed.

### 3.2 Everything that can exist, exists

**Argument ("no limiter"):** if something could exist but didn't, there would have to be a limiting factor, force or rule. That limiter would put certain things outside what can exist, which contradicts their being possible.

How it was strengthened inside the framework:
- **Any limiter would itself be a possibility**, so it would be inside the absolute and couldn't fence the whole from outside.
- **A "brute" limit fails too.** "Only some possibilities are actual" would be a distinction applied to the whole. But the absolute has no qualities and carries no information (3.4). So a limit on the whole would be a quality the whole can't have.

Note: this view is not widely held. Most philosophers separate "possible" from "actual" (actualism). David Lewis (modal realism) and Max Tegmark (mathematical universe) defend related views. The argument also resembles the principle of sufficient reason: limits need reasons. Someone who rejects that principle could accept unexplained brute limits. The framework answers with 3.4.

### 3.3 Contradictions aren't excluded from reality, they're empty pointers

An earlier proposal said "possible" means "draws a consistent distinction", so things like square circles are out. **I rejected this as unnecessary.** "Consistent" would be hard to define across all possible realities.

My position:
- "Square circle" is two written words. The words exist. The idea may exist in someone's mind.
- If anything in any reality can be pointed to as a square circle, it exists there. The pointing link may be arbitrary; language is itself just a pattern in possibility space.
- If nothing can be found, it's only a label, words or an idea.
- In one moment I can experience yellowness and not-yellowness (different parts of the visual field) with no contradiction.
- **So every contradiction is either an empty pointer or not a fundamental contradiction.**

Accepted refinements:
- A real contradiction would need the same thing to be yellow and not yellow, in the same respect, at the same time. That's an attempt to draw a distinction and not draw it. Nothing gets picked out, so nothing is excluded from reality.
- Contradiction lives in language, not in the absolute.
- Consistency still has a role, but as **a tool for checking whether a label points at anything**, not a law that limits reality. We know "the largest prime number" refers to nothing because we can prove it.

### 3.4 The absolute carries no information

The absolute contains every possibility, so it selects nothing. It has no qualities, yet contains all qualities.

**Analogy:** a library holding every possible book. "The library contains this book" tells you nothing. Being handed one book tells you a lot: this one and not the others. The information is in the pick, not in the library.

**Consequence: all information is local.** Every fact is, in the end, "this is the part of the absolute I'm in". "There is gravity here" is information only because other regions have none. The absolute is like a map of everything that tells you something only once there's a "you are here" dot.

A poem I find apt ("I AM"):

> I am
> I have no words to express Myself
> but all words express only Me
> I have no meaning
> but impart meaning to all that is perceived
> I am without beginning and end
> but all things begin and end in Me

### 3.5 The absolute is beyond all distinctions, including unlimited/limited

Any word for the absolute is inherently inaccurate. There is no limit to it from any side, in any dimension or way, and at the same time every limit exists within it or relative to it.

Even "unlimited" isn't fully true of it. If it were simply unlimited, that would exclude limitation from appearing anywhere in possibility space. **Its unlimitedness is so unlimited that it allows all limitations.**

It's also beyond the distinction between existing and not existing, since that's a distinction too and sits inside it.

Related views:
- Hegel's "true infinite": an infinite opposed to the finite is limited by it. The true infinite includes the finite.
- Nagarjuna: ultimate reality neither exists, nor doesn't exist, nor both, nor neither.
- Plotinus: the One is "beyond being".
- Nicholas of Cusa: in the infinite, opposites coincide.

## 4. What follows from the framework

1. **Information and existence apply only within the absolute**, never to it. Like a coordinate system that locates every point but isn't a point.
2. **Every rival metaphysics has a place.** Since the absolute allows all limitations, there can be regions where "only some possibilities are real" is the rule. Rival views are true locally, as the rule of some region, and false only as claims about the whole. The "no limiter" argument therefore shows not that rivals are meaningless, but that they take local truths for global ones. (I agreed with this.)
3. **"Excludes nothing" is a feature, not a flaw**, at the level of the absolute. The inner definitions still exclude and do real work.
4. **"Exists" separates nothing from anything at the global level.** Sherlock Holmes exists somewhere. The interesting questions become "where" and "relative to what", not "whether".

## 5. Objections raised and how they were handled

| Objection | Outcome |
|---|---|
| Information needs an effect on a second system (Bateson's "makes a difference"). | Rejected (3.1). Kept in the weaker form that distinction is relative to possibility space. |
| "Can exist" is empty unless defined independently; otherwise "everything that can exist, exists" means "everything that exists, exists". | Answered: the no-limiter argument plus 3.4 earns the identity of possible and existing. Within the framework the claim isn't empty, though it won't convince someone who rejects the premises. |
| Possibility should be limited to consistent distinctions. | Rejected as unnecessary (3.3). Consistency is demoted to a test for empty labels. |
| Cantor's theorem: any collection has more sub-collections than members, even when infinite. If every combination is a possibility, "the total of all possibilities" can't be a completed totality. | Answered by 3.5: the absolute isn't a completed set or total. Cantor himself called this the "Absolute Infinite", said it can't be a set, and linked it to God. Set theory treats collections too big to be sets as proper classes. |
| If every word for the absolute is inaccurate, is the theory only a pointer that can be gestured at but not argued for? | Partly answered by 3.5: statements about the absolute are approximations. Not fully settled (see 6.2). |
| An earlier criterion "to exist is to make a difference" would deny that numbers exist. | Replaced by "existence is being a distinct possibility". |

## 6. Open questions: possible breaks and blind spots

The aim is to test the framework, not to extend it. These are the points where it might fail on its own terms.

1. **Statements about the absolute.** Every word for the absolute is inaccurate. If they're all approximations, what makes some better than others? "Beyond all distinctions" seems more accurate than "unlimited", but by what standard, if no standard applies to the absolute? Without an answer, the framework can't defend its own claims about the absolute against rival claims.
2. **Self-reference.** The framework is itself a set of distinctions, so it sits inside the absolute. Is "all information is local" then only locally true? If so, does that undermine it, or is it consistent with the framework?
3. **Circularity.** Existence is defined through possibility, possibility through distinction, and distinction as one possibility against others. Is distinction simply a primitive, or is the circle vicious?
